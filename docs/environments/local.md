# Local Environment

El ambiente local es el unico ambiente con acciones ejecutables en este MVP.

Capacidades:

- Runtime local por Docker Compose.
- Jobs de calidad y pruebas.
- Observabilidad local.
- Deployments Fase 6 con plan, aprobacion, apply y verify.
- Documentacion viva Fase 7.

Guardrails:

- Comandos arbitrarios bloqueados.
- Secretos redactados.
- Rollback real requiere artifact/fingerprint previo verificable.
